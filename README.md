# Prosthodontic Clinical Decision Support System

## Overview

This project explores the design and development of a dual-facing Clinical Decision Support System (CDSS) for shared decision-making in prosthodontics.

Developed as part of a master's thesis in Global Public Health using Design Science Research Methodology (DSRM), the system aims to support structured, evidence-informed clinical reasoning and informed patient participation without replacing professional judgment or compromising patient autonomy.

## System design

The CDSS is connected to electronic health records using FHIR interoperability standards and SMART on FHIR to retrieve relevant patient data for the clinical case.

It utilizes a separate rule-based knowledge system for clinical evaluation, using the GDL2 rule-based expression language to define clinical rules. An explanatory knowledge layer provides supporting information to improve explainability and traceability.

The system uses a shared visual interface during clinical consultations, supporting clinical assessment and shared decision-making between practitioner and patient. It offers practitioners flexible yet structured decision support through standardized rules, traceable logic, and supporting evidence.

For patients, the system provides natural-language explanations of possible treatments and their attributes. It offers an opportunity to participate in treatment planning through patient education and visualization of treatment details and evaluation results.
